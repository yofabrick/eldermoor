# 03 — Game Loop

## Loop in One Sentence
**Improve base → prepare → expedition → capture & fight → process loot & beasts → unlock bigger ambitions.**

Same skeleton as Palworld / Ark, dressed in free wizard fantasy and Vita/Mortis identity.

---

## Early Game (hours 0–4)

**Goal:** Stop dying. Get one functional shelter and 1–3 weak beasts working.

| Step | Player action | Feeling |
|------|---------------|---------|
| 1 | Spawn in Wild Arcana (ruin / glade) | Disoriented, small |
| 2 | Gather wood, herbs, stone, essence | Hands-on survival |
| 3 | Craft basic tools, weak bonding focus / traps | First agency |
| 4 | Capture first low-tier beasts | “I own a creature” dopamine |
| 5 | Build primitive shelter + pen | Home exists |
| 6 | Assign beasts: chop / watch / haul | Automation seed |
| 7 | Survive first nights (mana, hunger, threats) | Tension |

**Tutorial design:** Show, don’t lecture. Fail states are recoverable nearby.

---

## Core Loop (the infinite middle)

Repeated in 15–45 minute cycles:

```
┌─────────────────────────────────────────────┐
│  1. BASE MANAGE                             │
│     Reassign beasts · check production ·    │
│     repair defenses · sort storage          │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│  2. PREPARE                                 │
│     Potions · gear repair/upgrade ·         │
│     capture tools · bonding runes · food    │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│  3. EXPEDITION                              │
│     Target biome or explore · farm mats ·   │
│     scout stronger beasts / ruins           │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│  4. CAPTURE & COMBAT                        │
│     Soften · bond/trap/charm · survive      │
│     wild beasts, dark creatures, rival AI   │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│  5. RETURN & PROCESS                        │
│     Craft gear · base upgrades · integrate  │
│     train new beasts · cook / refine        │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│  6. PROGRESSION GATE                        │
│     New region · magic branch · breeding ·  │
│     notoriety with Council ticks up         │
└─────────────────────────────────────────────┘
```

### Emotional rhythm
- **Base:** control, cozy/power fantasy, slight management  
- **Expedition:** risk, discovery, tension  
- **Capture:** skill expression + collection dopamine  
- **Return:** reward processing, “one more upgrade”  

---

## Mid Game Expansion

Once basic automation works:

- Multi-biome routes and mount travel  
- Specialized beast roles (crafter, tank, flier, alchemist-assist)  
- First serious **Vita or Mortis** commitment  
- Optional dungeons / ancient vaults  
- Trade or raid with AI enclaves  
- First **Inquisitor** attention if notoriety high  
- Breeding / mutation projects  
- Shared multiplayer bases become efficient

---

## Late Game Expansion

- Territory claims and defense  
- Boss beasts & world threats  
- Full production chains (potions, runes, munitions, constructs)  
- Player vs player or faction wars (server rules)  
- Planning the **strike against academies / Council**  
- Army composition of beasts + thralls / allies  

---

## Session Design Targets

| Session length | Ideal outcome |
|----------------|---------------|
| 20 min | One expedition + one base tick |
| 60 min | New beast tier or base wing + gear bump |
| 3+ hrs | Region push or multiplayer op |

**Quit point rule:** Always leave an unfinished but clear next goal on screen (quest pin, incomplete pen, scouted elite beast).

---

## Failure & Recovery
- Death: drop partial load / wound state (tunable); beasts may flee or defend  
- Base raid: repairs and revenge hooks, not total wipe of progress by default  
- Soft lock prevention: always a weaker biome and wild food path nearby  

---

## What the Loop Must Never Become
- Waiting for real-time day resets as the main content gate (Animal Crossing trap)  
- Capture without utility (collect-only Pokédex trap)  
- Story chapters that lock the sandbox for hours  
- Empty open world with 10-minute walks between meaning
