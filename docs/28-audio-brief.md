# 28 — Audio Direction Brief

## North Star
**Wonder with teeth.** Choir and folk for awe; iron and paper for institutions; creature Foley that sells *work*, not only battle cries.

## Music Stems
| Context | Palette |
|---------|---------|
| Thornwake explore | Soft choir, woodwinds, distant bells |
| Blackvein Mire | Low drones, wet percussion, detuned strings |
| Base safe (day) | Warm ostinato; productivity without cozy-trap |
| Night / threat | Heart-adjacent pulse, no jump-scare stingers spam |
| Vita zones | Major lifts, breathy vocals |
| Mortis zones | Parallel minor, bone/click motifs |
| Heat rise | Grey-gold motif: clean brass + parchment rasp |
| Council / Inquisitor | March of polite terror — measured, civilized |
| Capture opportunity | Distinct rising chime (dopamine) |
| Capture success | Short signature stinger (logo-level memorable) |
| Capture fail | Soft negative — informative, not punishing shame |

## Adaptive Layers
Explore stem + threat layer + Heat layer (0–1 mix). Path flag swaps color layer permanently after fork.

## Creature VO
- Each slice beast: 5–8 barks (idle, work start, work loop, hurt, capture fail, capture success, rare)  
- Hearthkin: near-language whispers  
- Ashcrown: crown-crackle + juvenile dragon without generic stock roar  

## UI / Foley
- Inventory: glass, cloth, chalk  
- Snare place: grit + rune hiss  
- Brand: iron sear (toggleable intensity)  
- Workforce assign: soft stamp + creature acknowledge  

## Diegetic Diegetic World
- Distant academy bells when Heat ≥3  
- Pamphlet flutter SFX  
- Magma Forge: industrial magic, not pure factory  

## Reference Direction (spirit, not temp tracks to ship)
- Wonder: selective Ghibli-adjacent softness  
- Teeth: darker folk / ritual percussion  
- Avoid: generic “epic trailer” library overuse as exploration bed  

## Slice Audio MVP
1. One explore loop per biome  
2. Capture opportunity + success/fail  
3. Base ambient  
4. Combat hits + 1 enemy set  
5. Heat motif sting  
6. Placeholder creature calls  

VO for player: optional barks only; not full performance capture in slice.
