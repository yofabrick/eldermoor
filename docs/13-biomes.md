# 13 — Biomes (World Structure)

## World Thesis
The **Wild Arcana** is not a theme park of schools. It is a **post-seal wilderness** where old civilization bones stick through living magic. Each biome teaches a new survival rule and unlocks a beast/job fantasy.

---

## Slice Biomes (ship in vertical slice)

### 1. Thornwake Glade (Starter)
| | |
|--|--|
| **Fantasy** | Enchanted forest that still remembers paths |
| **Threats** | Night crawlers, territorial boars, minor ward ghosts |
| **Resources** | Wood, softstone, glowherbs, minor essence |
| **Beasts** | Glimmerpouch, Brushback, Lantern Hare, Cinderscale, early Hearthkin |

| **Teach** | Gather, first capture, first night, first pen |
| **Visual** | Gold-green canopy, broken academy lanterns in trees, moss on cut stone |

### 2. Blackvein Mire (Contrast)
| | |
|--|--|
| **Fantasy** | Magic that rotted when seals broke |
| **Threats** | Poison fog, will-o’ drowning lights, Bogwhisper packs |
| **Resources** | Bog iron, toxin glands, black resin, deep essence |

**Optional slice swap:** Sky-ruin edge instead of Mire if art wants verticality earlier.

### Biome cards (post-slice)

**Ashfen Quarry** — industrial scars, golem-seeds, smelter heaven.  
**Whisperorchard** — living fruit that lies; Vita paradise with parasite risk.  
**Skyisles of Caer-Vell** — floating lecture ruins; Ridgespire nests; cargo beasts.  
**Mirror Dunes** — illusions, identity lore, “who am I” quest dens.  
**Frostglyph Tundra** — mana drought; strain management hard mode.  
**Warglass Fields** — crystallized spell residue; siege materials.  
**Hollow Academies** — dungeon-campus hybrids; Inquisitor spawns.

## Traversal Unlocks
1. Foot + basic wards  
2. Brushback / ground mount  
3. Ridgespire flight lanes  
4. Umbracourse night roads (skip some heat)  
5. Skyreel cargo routes between outposts  
6. Ritual portals (late, base-to-base)

## Environmental Magics
- **Ley weather:** mana storms buff spells, increase misfire  
- **Seal echoes:** temporary anti-magic zones near old wards  
- **Blight vs Bloom:** Mortis/Vita player actions permanently tint local cells  

## POI Types (repeatable)
Ruin library · Beast den · Abandoned pen · Shrine (Vita) · Brand pit (Mortis) · Trader wreck · Inquisitor camp · Player-claimable outcrop
