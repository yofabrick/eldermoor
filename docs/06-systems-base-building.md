# 06 — Systems: Base-Building & Automation

## Fantasy Arc
**Tent / ruin camp → cottage → mage tower → fortified enclave → private academy / fortress.**

You are not decorating a dorm. You are building a **power base** that can eventually challenge institutions.

## Building Language
- **Manual construction** + **magical assist** (levitation of beams, transfiguration of materials, beast labor)  
- Modular pieces with biome skins (woodland, mire-stone, sky-isle crystal, academy-spolia)  
- Vita bases trend living wood / gardens / light  
- Mortis bases trend bone-iron / brands / subdued flame / trophies  

## Core Modules

| Module | Function |
|--------|----------|
| Shelter / bed | Rest, save-ish, mana recovery |
| Storage | Materials, reagents, gear |
| Workbench family | Tools, gear, capture implements |
| Alchemy lab | Potions, oils, baits |
| Rune forge | Wand parts, brands, equipment |
| Creature pens | Capacity, happiness/control, breeding |
| Greenhouse / blight pits | Vita crops vs Mortis reagent farms |
| Defenses | Walls, towers, ward stones, beast posts |
| Production chains | Smelter, saw, loom, essence still |
| Ritual circle | Big magic, path ceremonies, multiplayer events |
| War room (late) | Siege planning, notoriety, faction stance |

## Automation Loop
1. Assign beasts to stations  
2. Stations consume fuel / food / essence  
3. Output fills storage  
4. Player designs chains (e.g. herb → still → potion → expedition prep)  
5. Efficiency upgrades reduce babysitting without removing all management  

**Goal feel:** “I can leave for 20 minutes of expedition and come back richer,” not “I must click every node forever.”

## Base as Story & Endgame Asset
- Higher base tier increases **notoriety**  
- Visible from world → attracts traders *and* Inquisitors  
- Final war uses your production (munitions, thralls, living siege engines)  
- Multiplayer: shared bases with permission ranks  

## Building Constraints (for fun, not busywork)
- Terrain stakes (cliffs, ley-line nodes, pure vs blighted soil)  
- Soft caps on workforce until pens upgraded  
- Supply lines if multiple outposts (mid-late)  

## Outposts
Unlock mid game: small resource camps in hostile biomes, linked by beast caravans or skyreels.
