# 07 — Multiplayer

## Design Goal
Multiplayer is a **pillar from day one**, not a post-launch checkbox. The fantasy is: *shared wilderness ambition* — build together, hunt apex beasts, raid ruins, and eventually war on institutions as a coalition or rival blocs.

## Modes (intent)

| Mode | Description |
|------|-------------|
| **Friends co-op** | Dedicated/listen or invite — shared or adjacent bases |
| **Persistent community world** | Larger pop, territory, markets, politics |
| **Solo with AI pressure** | Full game valid offline-first where possible |
| **Event layers** | Timed world bosses, Council purges, broom-race meets |

Palworld lesson: ship co-op early; scale social systems iteratively.

## Shared Fantasy Hooks
- Dual-binding a boss beast (ritual needs 2+ casters)  
- Shared production (one player industry, one player capture specialist)  
- Base defense nights  
- Territory claims and banners  
- Duels and beast tournaments  
- Coordinated academy siege in endgame  

## Conflict Rules
Configurable per server:
- PvE only  
- Optional PvP zones  
- Full open PvP  
- Consent duels  

Default public: soft PvP with claim protection windows to avoid pure grief as onboarding.

## Social Systems (phased)
**EA launch:** parties, shared chests, base perms, voice/text  
**Post:** trading posts, factions, wars, races, beast arenas  

## Anti-Frustration
- Personal progression not fully blocked by grief  
- Offline protection options for bases  
- Clear permission UI (build / inventory / beasts / diplomacy)

## Bind Contribution Score (v0.3 canon)
When multiple players contest a catchable beast, the host tallies:

| Contribution | Weight |
|--------------|--------|
| Soften actions (part breaks, interrupts, correct bait) | High |
| Method channel participation (pact, ward hold, dual brand) | High |
| Raw damage | Medium |
| Heals / peels that keep channel alive | Medium |
| AFK / random hits only | Near zero |

**Top scorer** receives bind rights (name + ownership). Others receive **mat share** and Dex credit (“assisted”).  
Server presets: **Fair score** (default) · **FFA** · **Round-robin** (friends).  
This is the answer to “co-op breaks capture economy.”

## Multiplayer Fantasy Checklist
- [ ] “We built a tower together.”  
- [ ] “We wiped a Council expedition as four mages and twenty beasts.”  
- [ ] “Our rivalry with the next valley is half the fun.”  
- [ ] “Solo still works when friends are offline.”
