# 12 — Beast Roster v1 (Vertical Slice + Stretch)

## Design Rules
1. Every beast must answer: **Work? Fight? Fantasy beat?**  
2. No pure Pokédex filler — if it only looks cute, give it a job or a joke with teeth.  
3. Names are original; archetypes may *rhyme* with familiar fantasy without copying IP.  
4. Tiers: **I** starter wilds · **II** biome specialists · **III** elites · **IV** apex (post-slice)

### Stat columns (1–5 relative to slice)
- **POW** combat power · **WRK** work efficiency · **SPD** speed/mobility · **WIL** resistance to capture/control · **SYN** path synergy (V=Vita lean, M=Mortis lean, N=Neutral)

## Capture Profiles (examples)

### Glimmerpouch
- Soften: almost none needed  
- Best method: **shiny bait** + quick snare  
- Fail funny: steals your reagent mid-cast  

### Hearthkin
- Soften: do **not** heavy attack (loyalty crashes)  
- Best: help clean a ruin shrine → **Vita-leaning bond**  
- Mortis brand: works but permanent craft penalty + base “cold” mood  

### Ashcrown Whelp
- Soften: break armor plates, avoid enrage  
- Needs **ritual circle** or 2-player bind for reliable catch  
- Reward: unlock Magma Forge module  

### Bogwhisper
- Soften: silence the croon, light wards  
- Mortis dominance easy; Vita bond requires cleansing quest

## Breeding (post-slice note)
- Parents pass **work bias**, **element**, and **path stain**  
- Mortis mutations can create unique combat forms that refuse greenhouse work  
- Vita pure lines raise enclave prosperity soft-cap
