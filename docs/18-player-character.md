# 18 — Player Character

## Fantasy
Not “the chosen student.”  
**The discarded practitioner who becomes a problem.**

## Creation (slice)
| Option | Notes |
|--------|-------|
| Body frame | 3–4 adult presets, non-sexualized default gear |
| Face / hair | Readable at distance; dirt and scars welcome |
| Voice | 2–3 VO barks sets or one androgynous set for slice |
| Pronouns | Player select; world uses them in rare VO/text |
| Name | Player choice; NPCs default to “Unlisted” / “Wildling” until reputation |

**No house sorting. No school uniform as default.**  
Starter look: ruined academy coat *stripped of insignia*, practical boots, wrapped hands, weak wand.

## Stats (soft, not RPG spreadsheet hell)

| Stat | Affects |
|------|---------|
| **Focus** | Channel time, bond stability |
| **Vigor** | HP, carry, melee shove |
| **Insight** | Weakness read, bait hints |
| **Authority** | Mortis control, intimidation |
| **Empathy** | Vita bonds, Hearthkin-like captures |

Stats rise via play style more than raw level grind (use X tools → gain). Soft level still exists for spell tier gates.

## Power Fantasy Beats by Stage
1. **Weak & clever** — traps over raw damage  
2. **Commander** — two beasts + smart spells  
3. **Enclave lord** — army and automation  
4. **Civilizational threat** — siege magic, path apex forms  

## Animation / Feel Goals
- Wand work: decisive, slightly desperate early; elegant late  
- Capture channel: feet plant, wind pulls leaves/ash  
- Mount calls: whistle + brand or living vine signal by path  

## What the PC is *not*
- Silent blank only (some personality barks OK)  
- Anime child protagonist  
- Pre-written romance gate for main plot  
- Moral saint by default
