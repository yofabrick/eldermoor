# Key Scenes — Slice

## Scene 01 — Discarded (cold open, ≤45s, skippable)
**VISUAL:** Gold sigils smear. Hands shove. Fall through seal-light into canopy.  
**VO (filtered):** “Failure is a kind of mercy.”  
**LAND:** Rain, ash-taste, weak wand spark.  
**UI:** Journal `???` · pin: *Survive the night.*  
**DESIGN:** No name entry forced; name can wait until first bed.

## Scene 02 — First bind (systemic, not cinematic rail)
Glimmerpouch steals shiny from player inventory mid-gather.  
Teaches: bait > brute force.  
On success: modal Party | Workforce | Pen. Recommend Workforce + scavenge.

## Scene 03 — First roof
Place bed + pen. Hearthkin *may* spawn nearby as rumor shimmer (not forced).  
Calder can appear at fence with trade crate if player approaches road.

## Scene 04 — Path Fork (amphitheater)
**Trigger:** ~6–8h or after first Mire return + still built.  
**Vale and/or Orun present as projections/remnants — not both fully if path is clear.**  
Honest tooltips show mechanical differences.  
Hold-confirm 2 seconds.  
World music stem swaps; UI chrome tints; one exclusive recipe mail.

## Scene 05 — Watcher
Non-combat. Ridge silhouette. If attacked, flees and +Heat large.  
Journal line auto. Heat pip animates open.

## Scene 06 — Envoy (Heat ≥3)
Mael or template. Dialogue tree:
1. Pay tax (essence) → Heat down  
2. Duel → skill check  
3. Refuse & leave → Heat up slow  
4. Ambush kill → Heat spike + loot + future strike weight  

No soft-lock. All options viable for some builds.

## Scene 07 — Ashcrown den (optional elite)
Boss music. Co-op pact ring glyphs.  
On bind/kill: Magma Forge schematic.  
Heat +10. Calder: “Congratulations. You’re interesting now.”
