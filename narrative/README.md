# Narrative Pack v0.4

Production writing samples — tone anchors for VO, UI, and quest text.

| File | Contents |
|------|----------|
| `journal-entries.md` | Player journal / memory shards |
| `barks-and-ui.md` | Beast, NPC, system barks + UI microcopy |
| `scenes-slice.md` | Key scripted moments (open, path fork, envoy) |
| `inquisitor-mael.md` | Voice sheet for primary antagonist face |

**Voice rules:** dry, slightly cruel, wondrous underneath. Institutions use polished euphemism. Never explain the joke twice.
