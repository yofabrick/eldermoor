# Eldermoor v0.7 — Full Greybox Arc

A browser prototype with **campaign milestones**, **boss**, **raids**, **Inquisitor duel**, **mount**, **wand progression**, **minimap**, and **pause menu**.

## Run

```bash
cd game/eldermoor-app
npm install
npm run dev
```

→ **http://127.0.0.1:5173/**

## Controls

| Key | Action |
|-----|--------|
| **WASD** / **Mouse** | Move / look (click lock) |
| **Space** | Dash · mount gallop |
| **E** | Gather · place build |
| **F** | Capture (Bond Ring) |
| **1–4** + **Click/Z** | Spells |
| **Q** / **G** | Craft snare / fodder |
| **B** | Build ghost cycle |
| **C** | Jobs + field party |
| **X** | Toggle field fighter |
| **M** | Mount Ridgespire |
| **U** | Upgrade wand (essence + ingot) |
| **V** | Vita / Mortis path |
| **T** | Save · auto-save ~90s |
| **Esc** | Pause · campaign checklist |

## What makes v0.7 different

### Inquisitor Mael (Heat ≥ 50)
Polite Council duelist — gold bolts, close brand, retreats or falls. Milestone + loot.

### Wand tiers
Cracked → Iron-bound → Rune Focus (**U**). More damage, mana, better captures.

### Beast bond levels
Field combat earns bond XP → stronger party damage (shown in party panel).

### Minimap
Player, stations, wild elites, Mire / boss / amphitheater POIs.

### Pause menu
Full campaign checklist, controls, wand upgrade button.

### Still in
Ashcrown boss · night raids · field party · Mire poison · Seal Echo · mount · day/night
